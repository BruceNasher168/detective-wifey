## Anti-Patterns & Negative Constraints

- **Never duplicate frontmatter triggers**: Do not add a `## When to Use` section in the body.
- **Never execute without preconditions**: Verify required files, tools, and containers exist before mutating code.
- **Never patch raw session specifics**: Keep procedures generalized; do not hardcode one-off ticket numbers or entity names.
- **Never skip verification**: Always compile, test, or inspect diffs before declaring completion.
- **Never burn LLM tokens on deterministic tasks**: Offload repetitive searching, artifact CRUD, and checklist validation to scripts in `scripts/`.
- **Never proceed on partial parallel executions**: When running scripts concurrently, always wait for all executions to finish before analyzing the outcome.
- **Never create unbounded loops or redundant reads**: Enforce hard retry limits and use targeted excerpts rather than repeatedly loading massive markdown files.
